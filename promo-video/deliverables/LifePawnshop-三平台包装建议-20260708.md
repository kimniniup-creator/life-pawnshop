# Life Pawnshop / 人生当铺 · 三平台包装建议（2026-07-08）

## 结论

这次不要把 Life Pawnshop 包成「AI 一晚做出爆款产品」。

更适合的叙事是：

> 一个很久没见的异国朋友想玩《五十公里桃花坞》里的人生卡牌。我们搜不到合适的小程序，于是当天搭了一个能和朋友线上开局的网页。先自己玩了四小时，边玩边改，现在把小项目拿出来给大家试试，也想收集更好玩的卡牌点子。

关键词是：朋友局、可玩小项目、一起补玩法、轻松但真实。

不要走：焦虑、AI 替代、效率神话、割韭菜式「不会 AI 就落后」。

## 发布顺序

1. 小红书图文先发
   - 用小条漫 + 游戏截图，最贴合这个项目的「朋友故事」。
   - 目标不是一次转化下载，而是让评论区产生「我也想玩 / 这张牌可以加什么」。

2. 个人 X 同步轻量 building-in-public
   - 发线程，不做硬广。
   - 重点是过程、截图、朋友反应、征集点子。

3. Bilibili 后置
   - 等小红书评论里有一些真实反馈后，再剪 2-4 分钟项目日志。
   - B 站不要只发 50 秒广告片，最好讲完整「怎么从想玩到搭出来，再到玩的时候哪里好笑」。

- 想试试的话评论区戳我，我发链接。

## 小红书

### 推荐形式

主推图文，不主推视频。

原因：

- 这件事的爽点是「朋友一句话 -> 小项目成形 -> 一起玩出话题」，需要读故事。
- 小条漫能把 OC、朋友关系、界面截图揉在一起。
- 视频之前最大问题是字幕、BGM、录屏清晰度和节奏；图文能绕开这些损耗。

### 正文建议

和一个很久没见的异国朋友在群里聊天，她突然说：好想玩《五十公里桃花坞》里那种人生卡牌游戏 🃏

我俩认真搜了一圈小程序，结果：没有。

于是当天就感受到了 vibe coding 的快乐。

下午只是一个「要是今晚能玩就好了」的念头，晚上已经在自己的网站里开桌，和朋友爽聊了四小时 🌙

规则大概是：开房间，选 7 样你最舍不得的东西，然后命运开始出牌。你可以硬扛，也可以典当；典出去的东西过两个回合没赎回来，就真的变成当铺的了。

最好玩的不是分数，是朋友会开始猜你：  
「你这个肯定舍不得当」  
「你怎么把这个押了啊」  
「这个结局也太像你了」

我们现在自己玩了一轮，也边玩边改了一版。想看看大家有没有更好玩的点子：爱情局、事业局、友情局、家庭局，或者一些更离谱但会让人沉默三秒的牌。

想玩的话可以评论区戳我，我发链接给你 ✨

喜欢的人多的话，我们就努力做成开放小程序，也持续更新卡牌模组，给大家拿去和朋友开局。

不是官方，只是一次「朋友想玩，所以把牌桌搭出来了」的小实验。

## Bilibili

### 推荐形式

先不发现有 50 秒宣传片作为主稿。

如果要发 B 站，更适合做 2-4 分钟项目日志：

> 朋友想玩桃花坞人生卡牌，我用 AI 搭了一个能线上开局的网页

B 站观众更需要「看懂你做了什么、为什么有意思、有什么过程」，而不是只看广告式成片。

### 视频结构

1. 0:00-0:10 钩子
   - 朋友说想玩，搜不到，所以做了一个。

2. 0:10-0:40 起因
   - 异国朋友、企鹅、纸袋头、群聊。

3. 0:40-1:30 游戏怎么跑
   - 开房间、选 7 张家底、稀有牌暗拍、命运出牌、典当/赎回。

4. 1:30-2:30 最好笑的地方
   - 朋友互猜、结局争议、玩着玩着开始认真。

5. 2:30-3:20 做的过程
   - 下午愿望、晚上网页、边玩边改。
   - 不要炫「AI 秒做」，而是讲「小需求可以更快被做成可玩的东西」。

6. 3:20-结尾 求助
   - 想加卡牌模组，欢迎评论区给牌。

现在可以开房间、选家底、暗拍稀有牌、典当/赎回，最后看每个人的结局。

### B 站注意

- 封面要清楚，不要黑屏、不要糊截图。
- 标题别太像营销课。
- 分区可考虑：科技 / 计算机技术 / 日常 / 桌游相关，最终按账号调性定。
- 如果后续上传，使用 Chrome Kim profile；发布前确认账号是 Kim。遇到 profile/native host 问题，回填 blocker，不声称已发。

## 个人 X

### 推荐形式

轻量 thread，4-6 条即可。

X 上不需要解释太满，适合保留「我做了个小东西」的即时感。

### 中文线程

1. 一个很久没见的异国朋友说，想玩《五十公里桃花坞》里那种人生卡牌。我们搜了一圈，没有找到能直接拉朋友线上玩的版本。

2. 所以我当天搭了一个小网页：开房间、选 7 样家底、命运出牌、典当/赎回，最后 AI 掌柜给每个人写一个人生结局。

3. 最好玩的不是规则，是朋友会开始猜你到底舍不舍得押：梦想、家人、爱情、自由，突然都变成可以被拿上牌桌讨论的东西。

4. 我们自己玩了四小时，一边玩一边改。现在想收一些卡牌点子：你觉得人生卡牌里最该出现哪张牌？

5. 想试的话评论/私信我，我发链接。喜欢的人多的话，我们就把它继续做成开放小程序。

### 英文/双语方向

如果发英文，重点不要写「Chinese reality show clone」，而是写：

> A long-distance friend wanted to play a life-choice card game together, so I built a tiny web version we could open in the same room.

这样更像 building in public，也更少版权/综艺绑定压力。
