# 人生当铺小红书图文稿 v1

## 方向判断

这条不应该再像“我做了一个游戏，大家来玩”。

更适合的内核是：

> 朋友一句想玩，我下午许了个愿，晚上真的搭出了一张能一起坐下来的牌桌。

它讲的是 vibe coding 最有幸福感的部分：不是效率炫技，而是把一个很小、很私人、很想和朋友一起玩的念头，快速变成真实体验。

## 标题备选

1. 朋友说想玩桃花坞人生卡牌，我当晚搭了一桌
2. 搜不到桃花坞人生卡牌，所以我自己做了一个
3. vibe coding 最快乐的瞬间：朋友想玩，我就搭桌
4. 下午一个念头，晚上和朋友玩了四小时

## 主推标题

朋友说想玩桃花坞人生卡牌，我当晚搭了一桌

## 图文结构：9 页小条漫

### P1 封面

画面：
小像素掌柜坐在牌桌后面，前景是几张人生底牌，背景像手机聊天窗口/小程序界面隐约压暗。

大字：
朋友说想玩桃花坞人生卡牌

副字：
我当晚搭了一桌

角标：
不是官方，是一次朋友局实验

### P2 起因

画面：
群聊气泡。一个很久没见的异国朋友发消息。

画面文字：
“好想玩《五十公里桃花坞》里那种人生卡牌游戏”

旁白：
我和一个很久没见的异国朋友在群里聊天。

她突然发了这么一句。

### P3 搜索

画面：
手机搜索页，关键词类似“桃花坞 人生卡牌 小程序”，结果空空。

旁白：
我们认真搜了一圈。

小程序，没有。

网页，没有。

像样的线上版本，也没有。

小字吐槽：
这时候人类就开始不甘心了。

### P4 转念

画面：
聊天气泡停在屏幕左边，右边出现一行很轻的代码/AI 对话窗口，不要太技术。

旁白：
以前遇到这种事，大概就算了。

但现在我脑子里多了一条新路径：

“搜不到，能不能直接做一个？”

强调字：
这大概就是 vibe coding 最快乐的瞬间。

### P5 搭出来

画面：
下午的许愿清单 -> 晚上的网页牌桌，中间用箭头或小漫画分镜连接。

旁白：
下午还只是一个念头：

要是今晚就能玩就好了。

晚上，我们已经坐在自己的网站里开始发牌。

小字：
当然，中间经历了一些字体很丑、BGM 很不对、录屏还坏掉的坎。

### P6 真正好玩的地方

画面：
多人牌桌，每个人面前有“人生 / 爱情 / 事业 / 家人 / 梦想”等卡牌。

旁白：
玩下来我发现，好玩的不是“抽卡”本身。

而是朋友会开始认真讨论一些很荒谬的问题：

如果必须押上梦想，你会换什么？

如果爱情和自由不能都留，你会怎么选？

### P7 掌柜机制

画面：
像素掌柜挑眉，牌桌上出现“典当 / 赎回 / 死当”的小机制卡。

旁白：
所以我给它做了一个“人生当铺”的壳。

你可以典当一些东西，换取当下更需要的资源。

但如果过了两个回合还没赎回来，

掌柜就会笑眯眯地收走。

掌柜小气泡：
喜欢您来。

### P8 朋友局

画面：
几个玩家的结局卡弹出来：好结局 / 平结局 / 坏结局。不要像广告，更像一桌人玩完之后互相看热闹。

旁白：
我们那天晚上玩了四个小时。

一边玩一边改：

哪张牌太轻，哪个选择太狠，哪个结局最让人想争。

我开始觉得，这不只是一个小游戏。

它更像一个能让朋友重新聊起来的道具。

### P9 收尾

画面：
掌柜把几张空白卡推到屏幕前，像是在邀请大家补充卡牌。

旁白：
目前只是我们自己玩了一轮，也顺手优化了一版。

如果你也想玩，可以评论区戳我，我发链接。

更想听听大家会往里面加什么卡牌模组：

爱情局、事业局、友情局，还是一些更离谱但会让人沉默三秒的东西。

底部小字：
如果喜欢的人多，我们就努力把它做成开放小程序，持续更新卡牌模组。

## 正文 Caption

和一个很久没见的异国朋友在群里聊天，她突然说：好想玩《五十公里桃花坞》里那种人生卡牌游戏。

我俩认真搜了一圈，小程序没有，网页也没有。

以前这种念头大概就算了。但现在我脑子里会多一条路径：搜不到，能不能直接做一个？

下午还只是一个“今晚要是能玩就好了”的愿望，晚上我们已经在自己的网站里开桌，玩了四个小时。

玩下来我觉得，真正有意思的不是抽卡，而是朋友会开始认真讨论一些很荒谬但又很像人生的问题：

如果必须押上梦想，你会换什么？
如果爱情和自由不能都留，你会怎么选？
如果过了两个回合还没赎回来，掌柜真的要收走，你会后悔吗？

这也是我觉得 vibe coding 很幸福的地方：它不只是让人更快完成工作，而是让一些很小、很私人、很想和朋友一起玩的念头，变成真的能坐下来体验的东西。

目前我们自己玩了一轮，也顺手优化了一版。想看看大家有没有更好玩的点子：可以加什么卡牌模组？爱情局、事业局、友情局，还是一些更离谱但会让人沉默三秒的东西？

想玩的话可以评论区戳我，我发链接。

如果喜欢的人比较多，我们就努力把它做成一个开放的小程序，也持续更新一些卡牌模组，给大家拿去和朋友开局。

不是官方，只是一次“朋友想玩，所以把牌桌搭出来了”的小实验。

## 视觉备注

- 不要做成游戏广告海报。每页像“一个想法被画出来”，不是功能介绍。
- 小条漫可以黑底像素风，但文字要白、清楚、少，不要古风硬字。
- 掌柜只做情绪钩子，不要让她讲太多台词。
- 每页一屏只讲一个转折：朋友想玩 -> 搜不到 -> 能不能做 -> 真做出来 -> 玩到上头 -> 邀请大家补卡。
- CTA 放最后，语气轻一点，不要“快来体验”。
